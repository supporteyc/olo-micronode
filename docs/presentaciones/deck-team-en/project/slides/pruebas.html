The four bugs: the receiver dropped events on a 404, which we found because another server was holding port 8080 on my machine; status failed when serializing ids from the database; the first cycle after an import called Olo more than needed; and an order that replaces another one stayed hidden. With a single command, dev:mock, you can bring everything up on your machine with no credentials or database. If there’s time, live demo here.
