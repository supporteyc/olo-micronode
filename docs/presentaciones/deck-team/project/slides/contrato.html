Lo que no cambia

La misma arquitectura por tienda, más un receptor central

Tablas

Mismo MySQL

menu_items, menu_item_changes, sync_runs, ocb_orders. Solo se suman 3 tablas nuevas.

Rutas

Mismo /api/toast/

menu-export, status, runs, menu-changes, ocb y scheduler, con la misma X-EC4-Key.

Reglas

Misma lógica

MENU_CONFIG, freno de borrado, preservar stock si la fuente falla, historial Yes/No.

www.eyecatch.co

Copiamos del repo de Toast el esquema, la autenticación, el filtro de menú, el freno de borrado y el historial. Hay tests que comparan cada respuesta con la forma de ec4toast-node: si alguien rompe el formato de menu-export o de status, el test falla. Las variables de entorno de Toast siguen sirviendo, incluso el nombre TOAST_SYNC_INTERVAL_MS.
