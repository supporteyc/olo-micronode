Why it exists

Olo is where we try new things. The Toast stores stay as they are.

The same per-store architecture, plus a central receiver. OnSign and the console don’t change a single line.

www.eyecatch.co

Worth saying up front: this is not a migration. The clients we have on Toast stay on Toast. Olo is the place to try everything new. And we built it so that, from the outside, it can’t be told apart from ec4toast-node: the OnSign server and the console talk to it the same way.
