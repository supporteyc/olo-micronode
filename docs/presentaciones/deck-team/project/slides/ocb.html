Ojo con un detalle: “Lista” en Olo no significa que la cocina terminó. Olo manda OrderClosed cuando se cumple la hora estimada; no documenta otra señal. Si una tienda no usa Expo, nunca llega OrderPickedUp, así que hay una configuración para ocultar la orden unos minutos después de OrderClosed. Las órdenes programadas esperan y aparecen cuando se disparan. Y cuando un cliente modifica una orden, Olo no cancela la vieja: manda una nueva que la reemplaza, y nosotros sacamos la original.
