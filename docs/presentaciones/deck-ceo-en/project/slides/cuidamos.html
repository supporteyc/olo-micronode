For operations

What happens when something goes wrong

If Olo does not respond

The screen keeps the last thing it knew. It never marks the menu as sold out because of an error.

If an update from Olo gets lost

Every 10 minutes we check the full sold-out list and fix things on our own.

If nobody picks up an order

It leaves the screen on its own, after 2 hours at most.

If a store goes offline

Its updates are saved and arrive in order when it comes back. Support gets an alert.

One thing for operations to know: when the screen says an order is ready, with Olo that means the estimated time has arrived, not that the kitchen said so. Olo does not send any other signal. We will confirm this with them. And if a store does not mark orders as picked up, we can set them to leave the screen on their own a few minutes later.
