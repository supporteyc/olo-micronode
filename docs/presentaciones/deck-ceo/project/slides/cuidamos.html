Para operaciones

Qué pasa cuando algo falla

Si Olo no responde

La pantalla se queda con lo último que sabía. Nunca marca el menú como agotado por un error.

Si se pierde un aviso de Olo

Cada 10 minutos revisamos la lista completa de agotados y corregimos solos.

Si nadie recoge una orden

Sale sola de la pantalla, como máximo a las 2 horas.

Si una tienda se desconecta

Sus avisos quedan guardados y le llegan en orden cuando vuelve. Soporte recibe una alerta.

www.eyecatch.co

Una aclaración para operaciones: cuando la pantalla dice que una orden está lista, en Olo eso significa que llegó la hora estimada, no que la cocina avisó. Olo no manda otra señal. Lo vamos a confirmar con ellos. Y si una tienda no marca las órdenes como recogidas, se configura para que salgan solas unos minutos después.
