The underlying difference: Olo doesn’t let you query the live menu to store it. So we went from asking every 78 seconds to listening for events and checking every so often. In practice, an 86 shows up in seconds instead of up to 78 seconds. Watch the ids: Olo uses numbers so large that JavaScript rounds them, so we always handle them as text.
